End-of-line equipment quality inspection

Harbor AI 2.0 Equipment Quality Inspection Platform

Designed an outgoing quality inspection solution from field requirements and existing sensing capabilities, with model-specific measurement and reference configuration.

  • Domain modeling
  • Measurement workflow design
  • Reference and threshold management
  • UI/UX
  • Feature-deviation analysis
Context
Per-item inspection, quality assessment and retained results before equipment shipment.
Core problem
Different equipment models require different stages and measurement points; sensing capabilities need a configurable inspection workflow with explicit decision criteria.
Challenges
Plans, work orders and test items need clear relationships, while reference changes, incomplete data and feature deviations must remain interpretable.
My contribution
Conceived the solution and designed plan → work order → test item relationships and the three-level principal UI; specified stages/points, reference recording and versioning, thresholds, NG/OK decisions and deviation analysis, and trained users on site.
Results
Established configurable measurement, reference comparison and analysis workflows, with on-site explanation and user training; formal acceptance remains unconfirmed.

Shares the Harbor AI 2.0 technical foundation with the monitoring platform, while serving different operational and delivery needs.

Context

Core problem

Challenges
