專業摘要

現任 Harbor Tech Data Scientist，從工業訊號分析、客戶交付到 AI 平台產品化，將振動、局部放電、剩餘壽命（RUL）與 LLM 方法接進可驗證、可維護的產品流程。主導產品與領域架構、資料與模型假設、診斷口徑及驗收條件，與工程夥伴和 AI agents 協作實作、測試及整合。

工作重點包括 Harbor AI 2.0、分析報告服務化、設備出廠檢測分支、離線部署與版本回復，以及持續運作的人與 AI 協作開發環境。研究背景涵蓋 DNA 序列與染色質交互作用預測、旅客流量預測、人物再辨識、時空分析與推薦系統。

  • AI／LLM 系統： LangChain／LangGraph、報告服務整合、vLLM、OpenAI-compatible APIs、deterministic facts、fallback、per-device isolation、人工驗證。
  • 資料科學與研究： Python、pandas、NumPy、SciPy、scikit-learn、CNN、多尺度模型、跨資料集評估、可解釋 AI（XAI）、統計檢定與效果量。
  • 後端與平台： Django／Django Ninja、Pydantic、PostgreSQL、Redis、RabbitMQ、REST APIs、async workflows、repository pattern、artifact-by-reference。
  • 產品與交付： React／TypeScript、Docker／Docker Compose、離線與跨架構安裝、release／rollback、資料遷移、Git、自動化測試、AI agents、人工審查。

RUL、診斷與模型假設驗證

  • 讓研究 notebook 直接呼叫正式產品程式，加入來源比對以降低研究與實作漂移；同時設計快速劣化漏報與健康序列誤報的品質條件。
  • 建立「前處理 → 有效振動區段篩選（VAD）→ 異常分類 → ISO 嚴重度 → RUL → 報告」責任鏈，將 fault type、severity 與 remaining time 分層呈現。
  • 檢查區段取樣、公平性、coverage、selection bias 與分母口徑；資料不足時顯式降級、給出區間或 unavailable，保留 engine raw output，避免 UI 或 LLM 改寫模型事實。現場壽命真值與信心校準尚未完成，不主張 RUL 準確率。
