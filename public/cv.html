專業摘要

現任皓博 Data Scientist，專注工業 AI 產品與客戶交付。主導 Harbor AI 2.0 工業智慧監控平台的產品與領域設計，以及設備出廠品質檢測從需求規格、系統開發到現場交付的專案；結合資料分析、系統整合與模型驗證，將分析方法轉為可操作、可驗證的產品。

獨立主導 MCIENet 碩士論文，涵蓋多尺度 CNN、資料流程、消融及跨資料集評估；另具客流估計、金融文本與人物再辨識研究及專案經驗。

技術能力

  • 資料分析與工業診斷： Python、NumPy、pandas、SciPy、scikit-learn、PyTorch；振動、局部放電相位圖譜（PRPD）、FFT、WAV、剩餘使用壽命（RUL）、統計檢定與效果量、CNN、消融及可解釋性分析（XAI）。
  • AI 與報告系統： LangChain、LangGraph 原型驗證、診斷報告服務整合、vLLM 端點能力驗證、OpenAI-compatible APIs、數值分析與 LLM 文字說明分離、多設備隔離、失敗備援與人工驗證。
  • 後端與產品： Django、Django Ninja、Pydantic、PostgreSQL、Redis、RabbitMQ、REST API、非同步工作流、React、TypeScript。
  • 工程與交付： Docker、Docker Compose、離線與跨架構安裝、版本更新與回復、資料遷移、Git、自動化測試、AI agents 與人工發布審查。

工業智慧監控平台

  • 產品與操作流程： 主導產品及領域設計，與團隊從 0 到 1 建構多數功能。將振動、PRPD、RUL、趨勢與資料品質轉為設備及感測器狀態、事件檢視與操作流程；以設備為報告入口，整合多語、圖表、行動版及 API。
  • 新舊系統演進： 設計設備資料與使用者設定的同步保護，避免舊系統覆寫新平台設定；推進設備控制權轉移、事件資料來源切換及資料遷移。感測器對應不明時停止匯入，補正後重新驗證；目前 2.0 已可獨立於 1.0 運作。
  • 分析任務與排程： 負責 Django 非同步工作流、跨服務整合與感測器排程，定義 API、資料存取、檔案引用、任務生命週期及失敗行為。以資料庫保存排程及執行狀態，整合手動觸發、批次與歷史查詢，依資料可用性選擇彙總或 WAV 輸入。
  • 邊緣資料與控制： 主責 Gateway 資料接收規格與方案驗證，涵蓋批次上傳、心跳、重複資料、完整性及容量邊界，交接對應工程師實作；另參與伺服器端軟體套件分發，以及 RUL 建議至平台閾值、歷史紀錄與 Gateway 更新的控制流程。

設備出廠品質檢測

  • 操作流程重整： 將需深入 5–6 層且出現循環導航的操作，重整為計畫清單、工單與看板三類核心介面；整併報告、複查及基準管理，加入集中主要動作、鍵盤操作、狀態與感測器脫落提醒，獲得 DQA 定性正面回饋。

  • 現場交付與排障： 2026.10.12 到場架設、示範及教育訓練，定位主機時間偏移造成的連線中斷，完成現場及後續修正；彙整客戶回饋並向團隊說明操作與設計調整。
  • 交付進度： 協調 DQA、測試版本、操作手冊及驗收紀錄。專案持續推進，正式簽核與最終驗收結果待確認。

工業分析、模型驗證與診斷報告

  • PRPD 指標溯源： 追查原始波形至分析與圖表的資料流程，辨識取樣點總數與離散放電事件率的差異；檢查頻段及相位聚合的物理意義，提出指標與介面語意的修正方向，候選脈衝率方案仍待驗證。
  • RUL 假設與實驗審查： 發現測試常數被當成觀測資料，撤回原分析結論並要求多參數、多曲線及正反向消融；讓研究 notebook 直接呼叫產品程式，檢查快速劣化漏報、健康序列誤報及實作差異。
  • 診斷與輸出規則： 整合前處理、有效運轉區段、故障分類、ISO 嚴重度、RUL 及報告，區分故障型態、嚴重度與剩餘時間；檢查取樣、覆蓋、選擇偏差及分母，資料不足時降級輸出並保留分析依據。現場壽命真值與信心校準仍待建立。
  • 報告服務產品化： 主導分析方法、報告結構及品質條件，從案場報告建立可重用流程；透過 LangChain、LangGraph 原型驗證節點契約、多設備隔離、局部重產及備援，再推進服務與平台派工、DOCX 報告及下載功能整合。數值與分類由分析節點產生，LLM 負責文字說明。
  • 模型服務能力驗證： 完成 vLLM 端點的 chat、embedding 及 tool calling 驗證，分別檢查連線、功能與語意結果，作為服務整合依據。

MCIENet｜碩士論文，2024

  • 以 DNA 序列預測 3D 染色質交互作用及 CTCF loops，設計多尺度 CNN、Inception 架構，檢視不同感受野的訊號。
  • 獨立主導問題拆解、模型與資料流程、實驗設計與執行、消融、跨資料集評估、可解釋性分析、論文撰寫及可重現程式整理。
  • 透過 BaseCNN 比較、序列長度及消融設定檢查模型設計；保留 DeepLIFT、ChINN、DNABERT2 比較入口及共用資料切分配置，已完成實驗與待重現設定分開記錄。
  • 將資料集、位置及解析度差異納入泛化檢查，辨識跨細胞類型的適用限制；部分正負樣本前處理改寫自 ChINN。

動態嵌入客流估計｜IIAI AAI 研究，2021

研究實驗方法｜2020–2024

  • 在有限 GPU 資源下以 Shell 安排並行實驗，曾於同一 GPU 執行兩組不同參數，分開保存紀錄及模型檢查點。
  • 將前處理結果存為 H5、使用 early stopping，先以三個參數值觀察曲線，再調整搜尋策略。
  • 上述方法隨金融文本、客流、PropGMAN 至 MCIENet 逐步累積，於 MCIENet 進一步整合消融設計與跨資料集評估。
