Projects/Distributed Spark Recovery

Course project

Distributed Spark Recovery

The course team connected data collection, time-series storage, missing-data detection, distributed models and dashboards.

My role
Responsible for the Spark cluster, GitHub collaboration and demo video. Used Vagrant for one master and two workers, supporting the team's recovery workflow integration.
Record period
2022 course project

The problem

Collection failures create time-series gaps, requiring detection, recovery and visualization.

Inputs, process and outputs

Inputs
Collected data, time-series storage and missing intervals.
Process
The team detected gaps and used distributed models to impute them. I built the Spark master/worker environment with Vagrant and handled GitHub and the demo video.
Outputs
A runnable course system and data-recovery demonstration.

Scope and limitations

Imputed values are model predictions. Team members separately handled collection, storage, models and dashboards.

Key problems and my approach

Make distributed infrastructure reproducible for the team

The course system needed multi-node processing and a reproducible cluster.

I used Vagrant to build a master and two workers on one computer, configuring connections, Java/Spark and startup instructions.

Built a documented, runnable cluster supporting integration of the team's data-recovery pipeline.

Explain separate modules as one end-to-end flow

After cluster startup, different members still owned collection, storage, recovery and charts. The demo needed to explain how data moved between them.

I handled GitHub and the demonstration video. The team README retained module instructions, while the demo connected raw data, imputation and charts. Teammates implemented models, crawlers and databases.

The team delivered a demonstrable course system with distinct cluster and integration-demo outputs from me. Imputed values remain model predictions.

Results and validation

The team completed a course system connecting collection, gap detection, Spark MLlib and dashboards.
