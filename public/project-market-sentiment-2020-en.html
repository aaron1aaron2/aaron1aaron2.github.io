Key design decisions

Define a learnable sentiment task in my first research project

ChallengePositive and negative news alone cannot describe a reader's arousal. My first research project required a clear question and annotation definition.

Approach and tradeoffsI completed the literature, data and model research, separating polarity and arousal. Five investors annotated independently; scores were averaged after removing extremes and handling disagreement. Annotator and coauthor contributions remain explicit.

ResultDeveloped a student project into a trainable classification task and a TCSE publication, building experience across problem definition, annotation, modeling and experiments.

When model changes stall, revisit data and comparisons

ChallengeRepeated model changes did not improve early results. Architecture changes alone could not distinguish data, parameter and representation limits.

Approach and tradeoffsI expanded the data and compared parameters and variants, combining HAN full-text and SAN sentiment-term representations. Validation data guided selection and a test set supported comparison. Exploration was less systematic at this stage; later work refined ablation and parameter strategies.

ResultRetained models, data and controlled comparisons, informing later research improvements. Sentiment classification is not evidence of investment returns.
