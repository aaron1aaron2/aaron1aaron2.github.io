Core problems and design decisions

Define a learnable sentiment task in my first research project

Positive and negative news alone cannot describe a reader's arousal. My first research project required a clear question and annotation definition.

I completed the literature, data and model research, separating polarity and arousal. Five investors annotated independently; scores were averaged after removing extremes and handling disagreement. Annotator and coauthor contributions remain explicit.

Developed a student project into a trainable classification task and a TCSE publication, building experience across problem definition, annotation, modeling and experiments.

When model changes stall, revisit data and comparisons

Repeated model changes did not improve early results. Architecture changes alone could not distinguish data, parameter and representation limits.

I expanded the data and compared parameters and variants, combining HAN full-text and SAN sentiment-term representations. Validation data guided selection and a test set supported comparison. Exploration was less systematic at this stage; later work refined ablation and parameter strategies.

Retained models, data and controlled comparisons, informing later research improvements. Sentiment classification is not evidence of investment returns.
