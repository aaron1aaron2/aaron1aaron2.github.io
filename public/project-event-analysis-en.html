Core problems and design decisions

Keep complete event history; retrieve only needed waveforms

Transferring all field waveforms would overwhelm transfer and analysis, while screenshots alone would not provide verifiable evidence.

I defined event-based selection, retaining the full database and using event times to retrieve relevant waveform windows. I aligned configuration, formats, naming and handover with field application and quality engineers.

Completed event analysis and report iterations with a repeatable handover process. Unselected periods are not claimed as diagnosed and do not support a full-period miss-rate estimate.

Connect separate tools into a reproducible delivery pipeline

Existing tools supported individual analyses but lacked a consistent workflow from event lists to accumulated plots and reports.

I used batch scripts to connect environment setup, event location, waveform organization, parallel processing and combined plots, then manually reviewed AI-assisted explanations.

Completed report and FAQ revisions and retained rerunnable steps from selection and intermediate plots through human review for handover.
